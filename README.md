# Parcours Data Analyst avec Excel

Ce dossier rassemble les supports d’un parcours progressif d’analyse de données avec Microsoft Excel, organisé en 24 journées. Il couvre les bases du tableur, les fonctions de calcul et de recherche, la préparation des données, la visualisation et les outils de modélisation analytique.

## Organisation

Les dossiers numérotés suivent l’ordre du parcours, du jour 1 au jour 24. Selon la journée, on y trouve un document pédagogique (`.docx` ou `.pdf`), un ou plusieurs classeurs d’exercices (`.xlsx`), ou les deux. Les fichiers Excel servent de supports de pratique et d’exemples ; les documents expliquent les notions et les activités.

| Jours | Thème |
|---|---|
| 01–05 | Environnement Excel, mise en forme, tri et filtres, validation des données, mise en forme conditionnelle |
| 06–10 | Opérateurs et calculs, fonctions statistiques et logiques, fonctions de texte et de date |
| 11–14 | VLOOKUP, XLOOKUP, INDEX et MATCH, tableaux Excel |
| 15–19 | Graphiques, tableaux croisés dynamiques, nettoyage et importation des données, dashboard interactif |
| 20–24 | Analyse commerciale, Power Query, Power Query avancé, Power Pivot et DAX |

Le dossier **18 Importation de données** contient également des fichiers de ventes mensuelles répartis dans des sous-dossiers, pour les exercices d’importation et de regroupement.

## Parcours conseillé

Suivre les dossiers dans l’ordre numérique. Pour chaque journée, consulter d’abord le document explicatif lorsqu’il est présent, puis ouvrir le classeur Excel associé et réaliser les exercices. Les jours qui ne contiennent qu’un classeur sont des supports pratiques.

## Formats

- `.docx` et `.pdf` : consignes, cours et rapports.
- `.xlsx` : classeurs d’exercices, jeux de données et exemples d’analyse.

Chaque dossier de journée et chaque sous-dossier de données possède son propre `README.md` avec une description de son contenu.
